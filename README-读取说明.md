# Jamie 作品集交接

本文件夹是当前本地作品集的完整独立副本，包含首页、8 个作品详情页、样式、脚本、图片及视频。

其他编辑器或 AI 软件可以直接打开整个文件夹。首页入口为 index.html；案例在 works 文件夹；素材在 assets、日落手机壳、支架等文件夹。请保留目录结构和中文文件名。

## 本地预览

安装 Node.js 后，双击 START-PREVIEW.cmd，在浏览器打开 http://127.0.0.1:4181/ 。保持预览窗口运行；关闭窗口后服务停止。

也可以在此文件夹终端运行 node preview_server.js，默认地址为 http://127.0.0.1:4173/ 。如果该端口被其他版本占用，请使用 START-PREVIEW.cmd。

网页使用从站点根目录开始的资源路径，因此请通过本地服务预览，不要直接双击 index.html。本项目为原生 HTML、CSS 和 JavaScript，无需安装项目依赖或构建。

## 当前调整

首页及详情页使用固定顶部导航，8 个案例页右上角有“返回作品”按钮，可回到首页浏览位置。

首页作品缩略图支持悬停放大、提亮和白灰渐变描边；“查看更多”按钮沿用首屏样式。右上角联系按钮为圆弧胶囊形。

首页电话显示为 134 3785 5695，点击可复制含空格的号码；底部联系区支持复制邮箱。联系区背景使用指定的桌面图片，保存为 assets/contact-background.avif；其标题、正文和署名采用按词错落、模糊渐显效果。个人介绍与职业经历保持直接可读。

近期交互集中在 home-feedback.css、home-feedback.js；文字动画在 staggered-text.js、staggered-text.css；共用导航在 global-nav.css。修改时请保留 index.html 中的样式加载顺序。

本副本可以独立编辑，修改不会同步回原工作目录。此文件夹未部署到互联网。
