III / 书籍装帧 企业画册类 / 2020

BREAKTHROUGH / BRAND PRACTICE

破局
2020

把品牌实践，编成一本可以持续阅读的年刊。

《破局 2020》以焰火云品牌的实践经验为内容主线，将品牌洞察、产品方法、渠道选择与合作案例重新组织为清晰的章节系统。设计通过城市影像、深蓝色调与强对比标题建立专业、理性的阅读氛围。

从封面到跨页，版式在大幅图像和高密度信息之间保持节奏，使复杂的商业内容更容易被理解，也让年刊本身成为品牌方法与成果的完整展示。

01 / CONTENT SYSTEM 章节与内容系统

从品牌介绍到方法论，建立连续的阅读路径。

章节页使用大幅城市影像划分主题，正文跨页通过明确的标题层级、信息图与留白控制阅读密度，让访谈、方法与案例各自保持清晰。

02 / BOOK IN CONTEXT 画册实景展示

让图像在翻页中展开，让信息随章节逐步进入。

实景展示保留书脊、纸张弧度与跨页关系，用不同开合角度呈现版式在真实印刷物中的层次和连续性。

III / 书籍装帧 企业画册类 / 崂山茶

LAOSHAN TEA / EDITORIAL SYSTEM

一页一景
一盏一味

从山场、人物到茶汤，建立晓阳春的完整品牌阅读体验。

画册围绕晓阳春的崂山茶产地、制茶人物、茶文化与产品体系展开。摄影承担自然气息与品牌温度，清晰的内容层级连接企业信息、人物故事和茶叶知识。

版式以留白为主，配合雾绿、茶褐和金黄作为识别色，使企业介绍与产品信息保持专业，也让山林、茶园和器物在翻页之间形成安静连贯的节奏。

01 / EDITORIAL OVERVIEW 内容与版式概览

以六组跨页建立从产地到产品的内容路径。

茶园风景、企业介绍、制茶人物、文化章节、生活方式与茶品信息采用不同图文比例，在同一套编辑系统中保持统一。
